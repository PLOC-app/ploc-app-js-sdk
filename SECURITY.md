# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/PLOC-app/ploc-app-js-sdk/security/advisories/new).

Include what you observed, how to reproduce it and the PLOC app version. We will acknowledge the report and keep you informed of the fix.

## Scope

This repository contains the client side of the SDK. Access control (permissions, authorization of native methods) is enforced by the PLOC app itself, not by `sdk.js`.
